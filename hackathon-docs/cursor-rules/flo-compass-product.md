## Key guardrails

- **We build:** session discovery, AI Q&A, local My Plan, interest personalization
- **We do NOT build:** registration, ticketing, check-in, badge printing, agenda CRUD, attendee admin
- Flo 2026: 3-day Gurgaon Office, ~640 parallel sessions; app complements Accelevents
- MVP order (do not reorder without team agreement): mock data → onboarding → discover → detail → my plan → companion
- Demo must state Accelevents complement explicitly
